# **1. Introducción.**  
  
**Descripción general:** Mission Control Es una plataforma digital de gestión de inventario inteligente orientada a el manejo de documentacion dentro de las empresas como lo es Passione (compañia ficticia). Su objetivo principal es eliminar el error humano y eliminar la ineficiencia de la memoria humana y poder llevar un registro exacto mediante una API y una base de datos.
  
**Audiencia:** Clientes finales, administradores del sitio, equipo de desarrollo y soporte técnico.
